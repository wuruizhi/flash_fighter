# 闪客快打 - Flash Fighter

经典横版格斗游戏 HTML5 复刻版 · 支持双人对战

## 🎮 游戏模式

| 模式 | 说明 |
|------|------|
| **1 单人闯关** | 独自挑战三个关卡 |
| **2 双人合作** | 两人一起闯关打敌人 |
| **3 双人对战** | P1 vs P2 格斗对决 |
| **4 键位设置** | 自定义操作按键 |

## 🕹 操作方式（拳皇风格 · 可自定义）

### P1 默认键位
| 按键 | 功能 |
|------|------|
| W/A/S/D | 上(跳)/左/下(蹲)/右 |
| J | 轻拳 (A) |
| K | 轻脚 (B) |
| U | 重拳 (C) |
| I | 重脚 (D) |
| 空格 | 必杀技（怒气满时）|

### P2 默认键位
| 按键 | 功能 |
|------|------|
| ↑/←/↓/→ | 上(跳)/左/下(蹲)/右 |
| Num1 | 轻拳 (A) |
| Num2 | 轻脚 (B) |
| Num4 | 重拳 (C) |
| Num5 | 重脚 (D) |
| Num0 | 必杀技 |

### 连招表
| 连招 | 按键 |
|------|------|
| 三连轻拳 | A, A, A |
| 轻拳→上勾拳 | A, A, C |
| 轻拳→回旋踢 | A, A, D |
| 轻脚→重脚 | B, B |
| 冲刺拳 | →→ + A/C |
| 跳跃飞踢 | 跳 + B/D |
| 下段扫腿 | ↓ + B |

## 🚀 部署

纯静态项目，无任何依赖。

```bash
# 方式一：Python
python3 -m http.server 8080

# 方式二：Node
npx serve .

# 方式三：Docker
docker build -t flash-fighter .
docker run -d -p 80:80 flash-fighter

# 方式四：Nginx 直接部署
cp -r * /var/www/html/flash_fighter/
```
